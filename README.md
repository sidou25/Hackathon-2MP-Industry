## 🎯 The challenge

The theme of the hackathon was to **build a website for a company**.

I chose to tackle a real problem that many Algerian companies face: **human-resources management is still done on paper or in scattered Excel files**. Attendance, leave requests, contract deadlines, payroll and **CNAS** (social security) declarations are tracked by hand, which leads to errors, forgotten renewals and lost time.

**2MP Industry** is my answer: a single web application that brings **CRM** and **HR** together in one dashboard.

## ✨ Features

### 👥 Human resources
| Module | What it does |
|---|---|
| **HR dashboard** | Daily overview: headcount, presence, pending requests, alerts |
| **Employee directory** | Full profiles, scoring, salary and seniority |
| **Time & attendance** | Daily check-in tracking, late arrivals and presence analysis |
| **Leave management** | Requests, approvals and planned absences |
| **Contracts** | Renewals, end of trial periods and contract compliance |
| **Payroll** | Payroll mass, payslips, salary levels and leave balances |
| **CNAS compliance** | Social-security administration and declarations |
| **Badge & document scanner** | Scan employee badges and documents |
| **Event history** | Full log of every HR action |

### 🤝 CRM
| Module | What it does |
|---|---|
| **Dashboard & analytics** | Key figures and charts |
| **Clients** | Customer portfolio |
| **Pipeline** | Sales opportunities, stage by stage |
| **Interactions** | History of calls, meetings and emails |

## 🛠️ Tech stack

- **HTML5**, **CSS3**, **JavaScript** (vanilla, no framework)
- **Chart.js** for the charts and analytics
- **localStorage** to save the data in the browser (no server needed for the demo)

Everything lives in a single `index.html` file, so the demo runs anywhere.

## 🚀 Run it

```bash
git clone https://github.com/sidou25/Hackathon-2MP-Industry.git
cd Hackathon-2MP-Industry
```

Then open `index.html` in your browser. That's it.

## 🇫🇷 Version française

> **2ᵉ place** à mon premier hackathon, à l'**École Supérieure de Commerce (ESC) de Koléa** — 2025.

**Le thème :** créer un site web pour une entreprise.

**La problématique que j'ai choisie :** dans beaucoup d'entreprises algériennes, la **gestion RH** se fait encore sur papier ou dans des fichiers Excel éparpillés : pointage, congés, échéances des contrats, paie, déclarations **CNAS**… Résultat : des erreurs, des renouvellements oubliés et beaucoup de temps perdu.
